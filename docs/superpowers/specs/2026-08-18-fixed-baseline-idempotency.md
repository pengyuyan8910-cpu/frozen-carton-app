# 固定确认版基准与幂等重排

当前正式排柜基准为用户已确认的 `整箱到店数据测算_最新产品池_20260817.xlsx`，有效SKU池67个。

当最新有效产品池与正式基准产品池一致、门店已存在于正式基准且正式冰柜配置未变化时，点击“全部门店重新排柜”或“重排指定门店”必须直接复用正式方案，不再次执行优化器。纳入SKU、柜位、列数、单列容量、单列占宽、满陈、直接整箱、外储、P95及建议外储不得漂移。

只有新增/淘汰SKU、明确SKU尺寸变化、新增门店或正式冰柜配置变化时，才进入现有统一严格排柜的增量优化链路。

柜4第1–5层正常参与冻品排柜；第6层仅存储。历史“新店柜4第1–4层预留”规则已取消，不得出现在算法、排序、验证或发布验收中。
