# 固定正式基准与重排幂等规则

## 已确认正式基准

正式底表以 `整箱到店数据测算_最新产品池_20260817.xlsx` 为当前67SKU确认版，并作为小程序重排基准。

## 幂等规则

当以下条件同时成立时：

- 最新有效产品池与正式基准产品池完全一致；
- 门店已经存在于正式基准；
- 门店冰柜配置未发生正式变更；

则点击“全部门店重新排柜”或“重排指定门店”不得再次优化该正式门店，必须直接复用正式方案。柜位、列数、单列容量、单列占宽、纳入SKU、未纳入SKU、满陈、直接整箱、静态外储、P95与建议外储均不得漂移。

示例：宁国津河西路生活馆在当前67SKU确认版中必须保持 67/67，建议外储343.7L；不能重新计算为1442L。

## 允许进入增量算法的情况

只有以下变化才进入统一严格排柜/业务优化链路：

1. 新增SKU；
2. 淘汰SKU；
3. SKU尺寸发生正式变化；
4. 新增门店；
5. 门店冰柜配置发生正式变化。

新增或变化完成后，经人工复核并导出最新版底表上传GitHub；该版本随后成为新的正式基准。以后在下一次变化前再次点击重排，应保持幂等。
